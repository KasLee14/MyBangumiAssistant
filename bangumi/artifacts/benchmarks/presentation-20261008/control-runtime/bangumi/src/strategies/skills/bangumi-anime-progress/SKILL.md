# 动画观看进度

先核实动画作品与章节，再按用户表达选择操作。作品收藏状态与章节状态是不同枚举；“看到”是官方补齐操作，不是新的章节状态。

## 确定范围

- “把动画设为看到第 N 集”“看到第 N 集”：只提交一个正篇目标，使用 `update_single_episode_collection`，参数为 `episode_id` 和 `batch:true`，不传 `collection_type`。由官方一次请求将同作品 `episodeType=0` 且 `sort` 不大于目标的正篇标记为看过；不要展开成多次逐集写入。
- “第 N 集看过”：使用 `update_single_episode_collection`，传 `episode_id`、`collection_type:2`，`batch` 省略或为 `false`。只修改这一集。
- “第 4～7 集看过”“第 4、7 集看过”等复数集请求：使用 `update_episode_collection`，明确传入 `subject_id`、`episode_ids`、`collection_type:2`。只修改用户列出的范围；不能改用最后一集的 `batch:true`，以免补齐未请求的前序章节。
- “看到”不会清除目标之后已有的观看状态，也不会修改 SP、OP、ED。用户明确要求倒退或取消后续状态时，需要另列指定章节操作；不能将官方补齐当成精确重置。
- 目标为 SP、OP、ED 等特殊章节时，不使用 `batch:true`；根据用户明确要求逐集修改，对“看到某特殊章节”的范围歧义先澄清。

## 核实作品和集数

- 通过搜索或已有工具事实确定动画作品 ID；同名漫画、其他季度和关联作品不能混用。对象明确后复用本轮有效事实。
- 读取正篇章节列表，按真实章节记录定位目标并取得 ID。正篇类型为 `0`；不能把集数当作章节 ID，不能通过 ID 加减推导相邻章节。
- 依据 `mainSequence`、`sort` 和标题核实用户说的集数；重号、不同光盘或编号歧义须先解决。官方补齐按 `sort` 比较，可能包含小数序号或同序号正篇，宿主会展示完整影响范围。
- 本人收藏使用 `get_user_subject_collection(username:"-")`。作品已收藏时保留收藏状态；未收藏时需先明确创建收藏，放在同一个完整计划的前置步骤，不默认替用户选择收藏状态。
- 个人章节状态通过 `get_user_episode_collection` 或单集读取核实。完整列表依照 `nextOffset` 续页；失败或不完整不能当作未标记。
- 不用已看集数汇总推断某集状态。即使目标集已经看过，前序仍可能有缺口；“看到”的整个范围均达成时才算无需修改。

## 提交与结果

- 所有写入统一放入一次 `execute_write_batch` 的完整 `operations`；同一请求涉及多部作品时一次收齐范围。章节状态操作免审批，无论单集、多集、官方“看到”还是多项章节操作，均不计入批量审批数量；混入其他操作时由宿主检查其确认政策，不拆成多个计划绕过确认。
- “看到第七集”的一项操作示例：

  ```json
  {"tool":"update_single_episode_collection","args":{"episode_id":1704798,"batch":true}}
  ```

  示例 ID 仅用于说明，实际必须来自工具核实。
- 动画进度不能通过 `update_subject_collection` 的 `ep_status` 或 `vol_status` 直接写入；这些参数仅用于已收藏书籍的章数/卷数。动画收藏响应的 `chapters` 是派生已看集数，以 `progressMeaning` 为准，不代表作品是书籍。
- 不为进度请求附带未要求的“在看”、评分、标签或短评修改。宿主负责核实完整影响范围、直接执行章节状态修改并独立回读；混合计划只有触发非章节操作的确认政策时才完整预览并确认，不在聊天中提前重复索取确认。
- 官方会同步计算已看集数，并可能更新范围内已看章节的观看时间。保留的后续已看或 SP 可能让汇总大于目标集数；不声称汇总必然等于 N。
- 只依据宿主最终 `state`、`summary`、`actual`、`verification`、`stageResults` 和 `parentProgress` 报告结果；底层提交回执不代表成功。明确列出已核实章节、跳过章节、依赖阻塞及未知结果，部分完成不能说成全部看过。条目错误和独立章节能否继续由宿主判定；未知章节及受影响父作品被隔离，不自动重发。账户/权限/授权变化或取消停止整批；用户后续要求补齐时先核实既有结果，再生成剩余范围的新计划。

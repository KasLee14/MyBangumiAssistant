# Bangumi 推荐

围绕用户本次目标选择作品，解释作品如何对应需求、必要取舍及依据。区分必须满足的条件与可权衡的偏好；大众评分、排序或关系本身不能证明个人适配程度。

已有候选和资料时直接比较。需要查找或补证据时，读取 [bangumi-query](../bangumi-query/SKILL.md)，通过候选引用完成召回、事实筛选和字段补全；需要社区观点时按需读取 [bangumi-community-read](../bangumi-community-read/SKILL.md)。软偏好可以帮助发现候选，不必全部拼成同时命中的标签条件。标签为语义线索，内容与体验判断依据本次取得的资料。

根据用户要求的数量和范围完成选择：少量推荐在所选作品的必要条件和理由有充分依据后交付；完整列表则继续处理指定范围。资料未知或读取失败不等于作品不适合，有限样本不代表全部作品或个人完整历史。收藏缺席须有适用的完整范围证据。

回答给出作品名称、链接和针对当前目标的理由，区分核实事实与适配判断，说明影响结论的资料或范围缺口。用户反馈用于调整当前目标；单次偏好不自动成为其他任务的固定条件。

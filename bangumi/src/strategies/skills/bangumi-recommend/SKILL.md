# Bangumi 推荐

围绕用户本次目标区分必须满足的条件和可权衡的偏好。评分、关系、标签和全文相关性只是线索，不能直接证明适合用户。

已有资料足够时直接比较；需要补充证据时读取bangumi-query Skill，使用六个本地只读工具召回、筛选、按需读取字段。当前没有向量检索；可用明确名称、别名、标签、关系和简介关键词寻找候选，但不能声称语义召回完整。用户标签缺席、简介缺失或未知不能解释为不适合。

推荐理由必须基于自己实际读取的资料。只拿到ID时先用fields或read_cached_resource读取判断所需证据。不要引用不存在的评论、个人收藏或实时网站状态。少量推荐在证据充分后交付；用户要求完整范围时继续分页并说明缺口。

交付名称、链接和针对目标的理由，区分核实事实与适配判断。SubjectCards使用resourceRef、所选ID和必要布局，由宿主直接从绑定快照补齐展示事实；Archive未提供封面时正常无图展示。用户要求表格时使用DataTable。推荐理由仍由模型写出，宿主补齐简介不等于模型已经阅读该简介。

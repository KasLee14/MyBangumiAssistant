# index：知识库入口

> 覆盖 `web/docs/agents/` ｜ 核对 2026-10-11

## 功能介绍

这是 `web/`（浏览器侧前端）知识库的**入口文件**。知识库只做两件事：**把 AI 送到该读的文件**、**统一开发风格**；它不是代码的事实源。

读法三步：在这里判断问题属于哪一层 / 哪一页 → 进该篇文档的索引定位到具体文件 → 打开源码交叉验证。

各层文档按「父级只描述当前层级、子级靠对子级的索引引导」组织；文档中的路径一律**仓库根相对**，以 `web/` 或 `bangumi/` 开头。改完代码要同步知识库，见本文档的「铁律」。

## 铁律

**1. 知识库不是事实源。**

- **规则**：知识库只用于定位；把知识库作为依据时，必须到真实源码中交叉验证。
- **为什么**：文档会滞后、会写错、会与源码不一致；它给的是路径与线索，不是结论。
- **后果**：拿过期描述当依据，会直接改错地方，而且错误会被「文档就是这么写的」掩盖，事后极难发现。

**2. 修改代码后一定同步更新知识库。**

- **规则**：完整完成开发任务之后，先给出**知识库更新方案**（改哪几篇、改哪些条目），经用户确认后再修改文档。
- **为什么**：知识库一旦与源码脱节就不可信，比没有知识库更糟。
- **后果**：下一次对话按过期文档改错地方。

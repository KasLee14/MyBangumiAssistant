# styles：文档页皮肤

> 覆盖 `web/src/page/library/styles/` ｜ 核对 2026-10-11

## 功能介绍

`web/src/page/library/styles/library.css` 是文档页专有的皮肤：只声明 `lib*` 前缀的类，不覆写共享类与内容组件的既有类（前缀分区见 [../../styles.md](../../styles.md) 规则 3）；令牌取自 `web/src/styles/base/`；引入顺序由 `web/src/main.tsx` 决定，排在 `content.css` 之后（顺序契约见 [../../styles.md](../../styles.md) 规则 6，`content.css` 必须已在，因为文档页要展示内容条目）。

## 索引

本目录只有文档页皮肤一处（见 [index.md](index.md) 的「按场景分流」）。

| 文件 | 含义 | 路径 | 场景 |
|---|---|---|---|
| `library.css` | 文档页皮肤：`.lib*` 前缀的骨架、卡片、参数表补充规则与导航补充规则 | `web/src/page/library/styles/library.css` | 改文档页布局或卡片形态 |

## 规则

### 单一真相源

**1. 与其它页共用同一套表面语言。**

- **规则**：文档页的顶栏用共享组件 `AppTopBar`、导航行用共享基类 `.appNavRow`、材质与圆角走 `--app-*` 令牌；本文件只补差量（如「参数表没有排序按钮」），**不另起一套顶栏、导航或卡片材质**。
- **为什么**：「工具页另有一套外观」这个例外已经取消，三个页面共用一套表面语言后，改令牌或共享类时三页一起变。
- **后果**：另起一套后文档页与主界面开始分叉，改共享基类时本页静默不跟随，而这种不一致只有在两页之间来回切换时才看得出来。

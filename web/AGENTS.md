# web：浏览器侧前端

`web/` 是 Bangumi AI 助手的 Web 终端界面：React 19 + 裸 redux + 手写 CSS，无 UI 组件库、无 CSS 框架。

**动手前先读知识库入口**：[web/docs/agents/index.md](docs/agents/index.md)。它把「要改什么」分到该读的那一篇文档；本文档只写每次写代码都必须读的内容。

## 不要做的事

**1. 引用链单向：路由 → 页面 → 组件 → 工具。**

- **规则**：只允许逆序引用（工具谁都能引，组件不引路由）；禁止组件引路由、工具引页面或组件、页面之间互引、顶层通用目录引 `web/src/page/**`。
- **为什么**：类型与常量是叶子层，`web/src/store/` 谁都能引；单向链一旦出现逆向引用就成环，模块初始化顺序会变成随机崩溃。
- **后果**：环上的模块谁先初始化不确定，症状随机、难复现，且构建未必报错。

**2. 页面入口只做装配，页面之间不互引。**

- **规则**：`web/src/page/<页面>/index.tsx` 只做装配；本页专有的组件、逻辑、常量、类型、样式分别进该页的 `components/` `utils/` `constants/` `types/` `styles/`，页面只引顶层与本页，不建页内 `common/`。
- **为什么**：判据是「谁消费它」——被两个及以上页面消费才进顶层对应目录，页面专有的留在页内。
- **后果**：页面互引会让两页无法独立改动；装配层混入业务逻辑后，改一处要读整页才能判断影响面。
